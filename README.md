# Portfolio Threshold — Dual-Lens Architecture

> An editorial and systems engineering portfolio designed with a dual-lens philosophical paradigm (**Structure vs Expression**).
> Built for **Bagja Iskandar Jamil** — Full-Stack Systems Architect, Frontend Engineer & AI/BCI Researcher.

---

## 🏛️ Philosophy & Concept: The Threshold

This portfolio rejects the conventional one-dimensional developer portfolio format. Instead, it offers two concurrent perspectives derived from the same source of authentic engineering truth:

1. **Structure Read (`/?lens=structure`):**
   - High information density, systems architecture diagrams, technical benchmarks, verified deliverables, and monochromatic telemetry design.
   - Built specifically for technical recruiters, engineering leads, and systems architects.
2. **Expression Read (`/?lens=expression`):**
   - Editorial storytelling, typographically rich narrative craft (Cormorant Garamond + JetBrains Mono), reflective engineering philosophy, and calm aesthetic balance.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 15 App Router (React 19 Server & Client Components)
- **Styling & Design System:** Tailwind CSS v3 with custom monastic palette (`deep-ink`, `ochre`, `cream`, `stone-graphite`)
- **Typography:** JetBrains Mono (monospaced systems) & Cormorant Garamond (editorial narrative) via `next/font/google`
- **Motion & Physics:** GSAP (GreenSock) animations with strict `prefers-reduced-motion` compliance
- **Smooth Scroll:** `@studio-freight/lenis`
- **Icons & Visuals:** `react-icons` (monochromatic brand SVGs) & `lucide-react` with custom algorithmic text monograms (`KMP`, `WPT`, `LDA`, `SRS`, `UML`, `RBAC`, `SDLC`, `SQL`, `REST`, `AI`, `AG`)
- **Data Integrity:** Strict TypeScript data contracts conforming to authentic engineering records (100% Zero Fabrication).

## 🚀 Getting Started

### Prerequisites
- Node.js 18.18+ or 20+
- npm or pnpm

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/bagja-iskandar/Portofolio_Threshold.git
cd Portofolio_Threshold

# 2. Install dependencies
npm install

# 3. Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
# Type check and build static production bundle
npm run build

# Start production server
npm run start
```
